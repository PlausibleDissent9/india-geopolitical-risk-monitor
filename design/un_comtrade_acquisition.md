# UN Comtrade acquisition gate

Status: **evaluate the free account before any purchase**. This is an internal
source-acquisition control, not a public IGRM data lane.

UN Comtrade is valuable because it can add an official India
reporter–partner–commodity–period layer. Premium increases throughput: bulk
files, larger calls and asynchronous delivery. It does not turn aggregate
customs statistics into buyer/supplier, shipment, route or port observations.
The provider also warns that transport-mode availability depends on the
reporter and that mode describes the border crossing, not an end-to-end route.

The controlled profiler runs ten public-preview queries per month: imports and
exports for cereals, mineral fuels, pharmaceuticals, machinery and electrical
machinery. It emits structural counts only. It does not retain rows, accept an
API key, write a repository file or authorize publication. One month uses ten
calls; two months use twenty, below the hard 24-call probe ceiling.

## Purchase rule

1. Create and exercise the free Basic account first. The provider documents
   100,000 records per call and 500 calls per day for Basic access.
2. Measure censoring, call volume, completion time, revision handling and
   extended-field coverage for India.
3. Obtain a written interpretation of recurring derived-output and
   redistribution rights. Record it through IGRM's signed rights-decision
   mechanism; do not infer permission from API access.
4. If Basic is actually insufficient, use the Premium trial after eligibility
   and measure the marginal benefit.
5. Buy only if the trial changes a named registered product. Faster extraction
   alone does not establish Atlas port, firm, shipment or route coverage.

Any future production lane needs immutable retrieval vintages because UN
Comtrade operates a single-current-version policy and provider revisions can
otherwise change historical results without an IGRM-visible trace.
