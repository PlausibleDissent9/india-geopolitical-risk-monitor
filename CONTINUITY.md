# Continuity plan (V21)

What happens to IGRM if the founder is unavailable for a week, a
semester, or permanently. Written while everything works, which is
the only honest time to write it.

## Degradation ladder, automatic

1. **Founder away days-to-weeks: nothing visible changes.** CI and
   the VPS publish daily; heal, receipts, bands, alerts, briefs,
   status all run unattended. The weekly note pauses (it is his
   voice, no machine substitutes); the site says its last note date
   honestly.
2. **Weeks-to-months:** calibration stays at its last n (flagged
   UNCALIBRATED at n<100 by rule); signatures queue in NOTES; the
   V11 experiment keeps grading itself — elapsed time is evidence
   either way.
3. **Permanent:** the last published data, methodology, validation
   record, and corrections ledger remain a valid dated instrument.
   Wayback snapshots (twice daily) and Software Heritage hold the
   record beyond igrm.in's hosting; the repo + REPLICATION.md let
   any third party rebuild and, under MIT/CC BY 4.0, fork and
   continue with attribution.

## Keys and single points of failure

GitHub account, VPS access, domain registrar, GCP service account,
Anthropic key: all founder-held. Annual renewal calendar: domain
(igrm.in, 5-year renewal recommended), GCP/API keys (rotate on
compromise only), VPS billing monthly. If the domain lapses, the
GitHub Pages origin remains live and archived.

## Annual rhythm (registered here)

- **January:** State of the Index report (V14) — the year's record:
  reliability, corrections, validation additions, negative results.
- **August:** registration review — every *_DRAFT older than 90 days
  either signs or is archived with a reason.
- **Continuous:** the review calendar above is itself append-only.

## Advisory board (the part no machine can do)

Recruiting reviewers who will sign their names is founder work.
The standing offer they accept: full pipeline access, the break-page
promise (submissions publish unedited), and a public annual review
slot in the January report.
