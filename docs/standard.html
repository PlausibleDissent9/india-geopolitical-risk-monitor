Overview
Current state: public draft 0.1.0. The schemas, reference validator and eleven-case conformance suite are implemented. This is not an ISO, BIS, government or industry-adopted standard, and IGRM has not yet issued a production canonical-object release: the production rights and release-signer registries remain deny-by-default.

One evidence boundary, tested as a system

OGES connects a signed release manifest to typed evidence, entities, events, declared-universe denominators and exposure edges. A conformant bundle must preserve exact schema and object bytes, signed source-rights decisions, executable method provenance, bitemporal ordering, privacy state, event-evidence roles and explicit quantified-versus-qualitative boundaries.

LayerWhat the gate bindsWhat it does not claim
EvidenceSource, retrieval, time, availability, rights state and hashesThat the source statement is true
EventActors, state, coding, evidence roles and confirmation eligibilityComplete ground truth
UniverseIncluded, excluded, unmappable and stale members against one frameCoverage outside the declared frame
ExposureEndpoints, method, denominator, period, uncertainty and limitationsRealized loss, causation or advice
ReleaseExact membership, policy snapshots and detached signatureGovernment or institutional endorsement

The suite cannot be passed by refusing everything

One complete deterministic synthetic release must pass. Ten independently registered variants must fail for their exact reason: signature tampering, role-spoofed official confirmation, a dropped universe member, an invented method, numeric data on a qualitative edge, a future measurement period, rewritten rights state, duplicate JSON keys, false object counts and exposed restricted evidence. No case may be skipped.

python -m src.oges_conformance profile
python -m src.oges_conformance self-test
python -m src.oges_conformance validate --bundle /path/to/bundle

The runner is offline. Its report contains the profile, validator and schema hashes, release ID, release hash, object counts and refusal codes—not evidence text, exposure values, credentials or private keys.

What a pass means

A pass licenses only this narrow statement: the supplied release conforms to OGES public draft 0.1.0 under the profile and test vector named in its report. It does not establish substantive truth, legal correctness of a signed rights decision, empirical independence of providers, causal attribution, forecast accuracy, comprehensive event coverage or endorsement by IGRM or any public institution.

The deterministic fixture keys are intentionally public test keys and must never be placed in a production trust registry. Production releases need independently controlled signer keys, real signed rights decisions and substantive review. The specification, machine profile, synthetic vectors and reference code are available under the repository's MIT License; reuse or conformance does not imply endorsement.
