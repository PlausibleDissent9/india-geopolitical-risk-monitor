Ask IGRM

Ask in your own words. A deterministic planner — the same routing rules as the repository's evidence-locked assistant, no language model — reads your phrasing and returns an answer that was verified against its source bytes (hash, JSON pointer, type, unit, date) before this page was published. Every value carries its evidence ledger. A question outside the registered space, or one the verifier cannot fully ground, gets a refusal with a stable code — never improvised prose. Your text stays in your browser: nothing is sent anywhere.
