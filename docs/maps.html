Inside India: events by state

Color: press-recorded events located in each state over the trailing 365 days, log scale from the calm color to the severe color. The table splits conflict (QuadClass 3 or 4) and protest (CAMEO root 14) shares. GDELT still emits some pre-2000 state codes; those are folded into today's boundaries and the fold is documented in the codebook. Telangana, Ladakh, and Goa show grey because the source's geocoding predates their current boundaries; their events are counted under the parent states, and an event-level re-split is queued.
