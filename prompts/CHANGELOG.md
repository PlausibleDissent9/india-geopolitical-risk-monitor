# Prompts changelog (append-only)

Prompts are registered instruments: versioned in this directory,
changed only by appending a new version here with a dated rationale,
never edited silently. Adopted from the indiconomics staging prompts
library design (2026-08-03).

## 2026-08-08 daily_brief 1.0.0 withdrawn

No new prompt version replaces 1.0.0. The experiment is disabled after ten
committed generated outputs exposed factual-grounding failures: unsupported
numbers, selection-induced denominator interpretations and a cross-date
score/receipt join. The registered prompt remains byte-preserved as incident
evidence. Re-enabling generated prose requires a new evidence-locked design,
not a prompt-only amendment.

## 2026-08-04 daily_brief 1.0.0

Initial registration, following the founder's approval of machine-
written daily summaries (NOTES_FOR_ISHAN.md 0.10, option b, approved
in chat 2026-08-04). Constraints encoded: measurement language only,
numbers over adjectives, machine-written labeling, no author voice.
